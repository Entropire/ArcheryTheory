# ArcheryTheory
Archery theory is a community driven website to distribute knolage about archery across the world. 

## Vision

The vision of this website is a place for archers from every discipline to have a central place for information about archery.
For the first stage I want to focus on tuning.
I want to help people with tuning through this website in these ways: 
- Give detailed description of how to tune every part of your setup.
- A step-by-step guide that takes an archer through the right steps to get the best tune possible/
- A way to save there setup and tunes so they can go back and know precisely how there bow was tuned.
- For every tuning step multiple ways to do it. This is because you can buy more and more precise aquipment for tuning but it is also posible with out it it wil just be less precise.
- Multiple tuning guide for beginner, intermidiat and prof. Every step requires more equipment for preciser tuning and goes more in depth on the tuning process.
- As up-to-date information as possible. I want this website to be correct with the current findings. I want to do this with community help, where the community can make a ticket for parts they think need to be changed.
- Prove for why some techniecks/ways are better than others. By supplying prove and research papers on the website.

## Development

Requires Node.js 22.22 or newer.

```bash
npm install     # install dependencies
npm run dev     # start the dev server on http://localhost:4321
npm run build   # type-check and build the site into dist/
npm run deploy  # build and publish dist/ to the Live branch (served by Cloudflare Pages)
```
